# Code of Conduct

Orbitrace adopts the **Contributor Covenant, version 2.1**, by reference. The full text, including its enforcement guidelines, is at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

Version 2.1 is the version that applies here, even if a newer version is published.

## Summary

- Be respectful and assume good faith in issues, pull requests and discussions.
- Keep feedback about the work, not about the person.
- No harassment, insults, personal attacks or unwelcome sexual attention.
- Do not publish someone else's private information without their permission. That includes their transcripts, file contents, paths and email addresses.
- A maintainer may edit, hide, close or lock content that breaks these rules.

## Reporting

Report a conduct concern privately, in either of these ways:

- Use GitHub's private reporting for this repository (**Security and quality** tab, **Report a vulnerability**), if it is enabled. Say in the title that it is a conduct report.
- Contact the repository owner, [@farisology](https://github.com/farisology), on GitHub. If you need a private channel, open an issue that asks for one and leave out every detail.

Do not post the details of a conduct concern in a public issue or pull request.

## Enforcement

The repository owner handles reports and follows the enforcement guidelines in the Contributor Covenant 2.1 text linked above.
