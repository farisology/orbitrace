# Code of Conduct

Orbitrace adopts the **Contributor Covenant, version 2.1**, by reference. The full text is at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Summary

- Be respectful and assume good faith in issues, pull requests and discussions.
- Keep feedback about the work, not about the person.
- No harassment, insults, personal attacks or unwelcome sexual attention.
- Do not publish someone else's private information, including their transcripts, emails or file contents, without their permission.
- Accept that a maintainer may close, edit or lock a thread that breaks these rules.

## Reporting

Report a conduct concern in either of these ways:

- Use GitHub's private reporting for this repository, through the **Security** tab, if it is enabled.
- Contact the repository owner privately through their GitHub profile at https://github.com/farisology.

Do not post the details of a conduct concern in a public issue or pull request.

## Enforcement

Enforcement follows the Contributor Covenant 2.1 enforcement guidelines, linked from the full text above.
