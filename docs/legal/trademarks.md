# Trademarks and names

This is a working note by the maintainers. It is not legal advice. It records how this project refers to other parties' names and what was checked on which date. If something matters legally, ask a lawyer.

## Independence statement

Use this line in the README, the docs and every listing (npm, VS Code Marketplace, Open VSX, plugin marketplace):

> Orbitrace is an independent project. It is not affiliated with or endorsed by Anthropic.

## Referring to Claude and Claude Code

Rules for docs and listings:

1. Refer to "Claude" and "Claude Code" only to say what Orbitrace works with, for example "replays Claude Code sessions".
2. Never put "Claude", "Claude Code" or "Anthropic" in the product name, package names, extension id, repository name, domain or logo.
3. Do not use Anthropic logos, artwork or Claude Code's visual style.
4. Do not write anything that suggests Anthropic sponsors, endorses or is connected to Orbitrace.
5. Do not add a trademark symbol next to those names. The guidelines say marks must not carry one (see below).
6. Use the words as plain text, in the form Anthropic uses them. Do not alter them.

Source: [Anthropic trademark guidelines](https://www.anthropic.com/legal/trademark-guidelines), page read on 26 Nov 2026. What the page says, quoted:

- "You may only use our trademarks as specifically permitted by us and only in materials we approve beforehand."
- On sponsorship: "You may not use our trademarks in a manner that implies Anthropic's sponsorship or endorsement" or "a relationship or affiliation with Anthropic, except as we expressly authorize."

Other points on the page, paraphrased (not quoted): the marks may not be altered in colour, font or proportion; uses that could harm Anthropic's reputation are prohibited; the marks should not carry a trademark symbol; Anthropic owns the marks and the goodwill. The page states an effective date of 1 August 2024 and says Anthropic may update it.

Unverified: the page, as read, has no passage that explicitly allows descriptive references such as "works with Claude Code". Rules 1 to 3 and 6 are the maintainers' cautious reading, not a statement from Anthropic. Reading is based on a fetched summary, not a manual read of the page in a browser. Re-read the page before the first public listing. If permission is needed, the guidelines page gives a contact for businesses that already have a relationship with Anthropic; this project has none.

## Spelling in listings

Write "Visualizer" (with a z) in listing titles and descriptions. This is a maintainers' decision for consistency, not a legal requirement.

## "Orrery" and "Orbitrace"

The product name is Orbitrace. "Orrery" is the generic name of the view: the main agent in the centre, subagents in orbit. It is an ordinary English word for a mechanical model of the solar system. Docs say "the orrery view" and never use "Orrery" as a product or package name. Unverified: no search was made for other products called Orrery.

## Agent Flow

Agent Flow is a separate project by Simon Patole. Its README says the name "Agent Flow" and its logos are trademarks of Simon Patole ([github.com/patoles/agent-flow](https://github.com/patoles/agent-flow), read 26 Nov 2026). Orbitrace does not use that name or those logos. See `NOTICE` for the licence note.
